A tiny Node program that writes a single username word — Wobble — to /output/entry.txt for make.fun's "One Word, One Username, One Reward" bounty. It checks the word against the gate (one word, 1–30 characters, no whitespace) before writing it with no trailing newline.

## Run it

```sh
node main.ts
```
